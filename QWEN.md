# Инструкции для Qwen: swrobotcompany-dev/-

## Контекст репозитория
- Имя репозитория — ровно один символ `-`: `swrobotcompany-dev/-`. Не подставляй вместо него название игры.
- Основная ветка — **main**. `master` — устаревшая ветка, уже влита в `main`; **не используй master как источник нового PR**.
- Существующий PR #1 из `2d-racing-game-refactoring-76fca` конфликтует с `main`: это отдельная версия игры. Не переключайся на его ветку, не перезаписывай её и не пытайся автоматически слить этот PR.
- Рабочий проект сейчас находится в `index.html`. Сохраняй его, пока пользователь явно не попросит заменить.

## Для КАЖДОЙ новой задачи по коду
1. Обнови данные из GitHub (`git fetch origin`) и начинай **новую** ветку от актуальной `origin/main` (например, `qwen/fix-menu-20261017`). Не начинай от `master` и не переиспользуй старые ветки.
2. Проверь, что `git diff origin/main` действительно содержит изменения, прежде чем открывать PR.
3. Зафиксируй изменения и отправь новую ветку: `git push -u origin <имя-ветки>`.
4. Создай PR **из новой ветки в main**, в репозитории `swrobotcompany-dev/-`. Пример:
   ```sh
   gh pr create --repo 'swrobotcompany-dev/-' --base main --head '<имя-ветки>' --title 'Краткое описание' --body 'Что изменено и как проверено'
   ```
5. Проверь, что PR создан, и отправь пользователю рабочую ссылку вида `https://github.com/swrobotcompany-dev/-/pull/<номер>`. Не заявляй об успехе, пока ссылка не получена.

## Если создать PR не получилось
- Приведи пользователю **точный текст ошибки** GitHub/API. Не пропускай этот шаг молча.
- `422: No commits between main and master` означает, что из старого `master` нет новых изменений. Создай новую ветку от `main` и вноси изменения в неё.
- `mergeable_state: dirty` означает конфликт уже существующего PR, а не общий запрет на создание новых PR.
- Если `403` / `401`, проверь права токена/приложения на запись в Contents и Pull requests, а также `gh auth status`. Для сайта Qwen Chat проверь настройки подключения GitHub в самом Qwen.
- При `gh`-ошибках: `git remote -v`, `git status`, `git branch --show-current`, `gh auth status`.
- Не помещай ключи доступа в репозиторий и не проси вставлять токен в код.

Этот файл описывает процесс; он **не подключает** Qwen Chat к GitHub и **не меняет** права приложения.
