# Тачка на прокачку — гараж и тест-драйв 🚗

Браузерная мини-игра с четырьмя автомобилями, выбором лакокрасочного покрытия, дисков и **играбельным испытательным полигоном**. Без сервера, сторонних библиотек и установки npm.

## Запуск

Открой `index.html` двойным кликом в Chrome, Firefox или Edge. Можно запустить простой локальный сервер:

```bash
python3 -m http.server 8000
```

После этого зайди на http://localhost:8000. В Windows команда может называться `py -m http.server 8000`.

## Возможности

- Четыре различных профиля кузова: **Toyota Mark II, Lada Vesta, Porsche 911 и Bugatti Veyron**. Каждый имеет собственный SVG-контур крыши, остекления, дверей и характерных деталей.
- Детализированные колёса, диски со спицами, тормозные механизмы, фары, зеркала, ручки, решётка, окрашенный кузов с бликами и арки колёс.
- 10 цветов кузова и три варианта дисков (стандарт / спорт / гоночные).
- Текущие характеристики скорости, управляемости и мощности влияют на поведение автомобиля во время тест-драйва.
- **«💾 Сохранить»** записывает выбор машины, цвета и колёс в `localStorage`: настройки восстановятся после обновления страницы.
- **«🏁 Испытать машину»** открывает управляемый полигон с трассой, контрольными точками, конусами, разным сцеплением на асфальте и траве, дрифтом, секундомером и рекордом круга для каждой модели.

## Управление на испытательном полигоне

| Клавиши | Действие |
| --- | --- |
| W / ↑ | Газ |
| S / ↓ | Тормоз / движение назад |
| A,D / ←,→ | Руль |
| Пробел | Ручник / занос |
| R | Вернуть автомобиль на старт |
| Esc | Вернуться в гараж |

На сенсорных экранах также доступны экранные кнопки.

**Как засчитать круг:** проезжай через светящиеся контрольные точки **по порядку**. Результат записывается после прохождения финиша; лучший круг сохраняется в этом браузере.

## Файлы

```text
.
├── index.html           # HTML-разметка интерфейса
├── assets/
│   └── css/
│       └── style.css   # Стили гаража, кнопок и полигона
├── src/
│   ├── garage.js       # Кузова SVG, диски, выбор и сохранение авто
│   └── testdrive.js    # Canvas-трасса, движение, физика, круги, таймер

```

Внешних зависимостей нет. Статика работает без сборки. Исходный `index.html` до рефакторинга остаётся в истории Git.

## Где отлаживать

- **Кузова** и конкретные SVG-пути машин: `CAR_PROFILES` в `src/garage.js`.
- **Диски и подсветка**: `wheelSVG()`, `renderCar()` в `src/garage.js`.
- **Физика**: `updatePhysics()`, коэффициенты ускорения, сцепления и сопротивления в `src/testdrive.js`.
- **Трасса**: `TRACK`, `GATES`, `CONES` и `drawTrack()` в `src/testdrive.js`.
- **HUD** и счётчики: `updateDashboard()`; разметка в `index.html`.
- **Внешний вид**: `assets/css/style.css`.

Тест-драйв пока представляет собой **вид сверху (2D Canvas)**; это не полноценный 3D-симулятор и не цифровой двойник реальной машины. Физика игровая, но содержит инерцию, боковое скольжение, различие покрытия, торможение и рулевое управление. Для точных размеров лицензированных кузовов нужны реальные CAD/3D-модели.
