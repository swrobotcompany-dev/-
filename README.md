# Тачка на прокачку 🚗

Мини-игра «автосалон-тюнинг» в браузере: выбираете модель авто, цвет и колёса — машина перерисовывается в реальном времени, а характеристики (скорость, управление, мощность) обновляются на шкалах.

Проект не требует сборки, установки зависимостей или сервера — достаточно открыть `index.html` в любом современном браузере.

## Запуск

```bash
# просто откройте файл в браузере
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

## Возможности

- **4 модели авто**: Toyota Mark 2, Lada Vesta, Porsche 911, Bugatti Veyron — каждая со своим SVG-силуэтом и базовыми статами.
- **10 цветов кузова** с автоматической генерацией светлых/тёмных оттенков для градиента и обводки.
- **3 типа колёс**: стандартные, спортивные, гоночные (CSS-диск с conic-gradient).
- **Живые характеристики**: полосы «Скорость / Управление / Мощность» пересчитываются при выборе модели и колёс (бонусы от обвеса).
- **Кнопка «Сохранить тачку»** с всплывающим уведомлением.
- Тёмная «гаражная» тема: градиентный фон, пол гаража, тень и блики машины.

## Структура кодовой базы

Проект — один самодостаточный файл:

```
.
├── index.html   # вся игра: разметка, стили и логика (~670 строк)
└── README.md    # этот файл
```

Внутри `index.html` три блока:

### 1. CSS (`<style>`)
- Оформление контейнера «гаража» (1400×800), панелей тюнинга и характеристик.
- Классы `.wheel.standard / .sport / .racing` — визуальные стили колёс.
- Стили кнопок `.part-btn`, палитры `.color-btn`, уведомления `.notification`.

### 2. HTML-разметка
- `#car-svg` — холст с `<defs>` (градиенты кузова/стёкол/фар, фильтр тени); кузов дорисовывается из JS.
- Панель 🔧 Тюнинг: кнопки моделей/колёс через `data-part` + `data-value`, контейнер `#color-picker`.
- Панель 📊 Характеристики: `#speed-stat`, `#handling-stat`, `#power-stat`.

### 3. JavaScript (`<script>`)
- `carProfiles` — данные моделей: SVG-пути (`body`, `windows`, `details`), позиции фар/фонарей, базовые `stats`.
- `currentConfig` — текущая конфигурация `{ model, color, wheels }`.
- `updateCar()` — пересобирает SVG по профилю выбранной модели (path/ellipse/rect через `createElementNS`).
- `updateStats()` — применяет бонусы колёс и обновляет ширины полос характеристик.
- `adjustColor()` — утилита осветления/затемнения HEX-цвета.
- `saveCar()` — показывает уведомление о сохранении.

## Стек

- HTML5 + CSS3 (flexbox, градиенты, transitions)
- Vanilla JS (без фреймворков и зависимостей)
- SVG (машина рисуется программно из SVG-путей профиля модели)
