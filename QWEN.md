# Инструкции для Qwen — swrobotcompany-dev/-

## Проект и ветки
- Точное текущее имя репозитория: `swrobotcompany-dev/-`. Не путай его со `standoff`.
- Основная ветка — `main`. Ветка `master` уже была влита и отстаёт от `main`: **не создавай PR master → main**.
- Файл `index.html` — текущая игра. Не заменяй её другой игрой без прямого запроса пользователя.
- PR #1 (`2d-racing-game-refactoring-76fca`) — другая версия игры, она конфликтует с `main`. Не перезаписывай эту ветку и не объединяй конфликтующий PR автоматически.

## Для каждой новой задачи
1. Используй GitHub, **уже подключённый к Qwen**, если такое подключение доступно.
2. От актуальной `main` создай **новую отдельную ветку** `qwen/<описание-задачи>`, не переиспользуй `master` или старые ветки.
3. Сделай запрошенное, проверь изменения и создай коммит в новой ветке.
4. Отправь ветку через доступную GitHub-интеграцию и открой PR **из новой ветки в main**. Убедись, что действительно есть коммиты между ними.
5. Подтверди успешное создание PR **его реальной ссылкой** `https://github.com/swrobotcompany-dev/-/pull/<номер>`. Коммит или push — ещё не PR.

## Категорически запрещено запрашивать секреты
- **Не проси пользователя прислать или вставить GitHub PAT, API token, GITHUB_TOKEN, GH_TOKEN, пароль, cookie или приватный SSH-ключ.**
- **Не отправляй пользователя на создание токена или настройку `gh auth`**, если задача выполняется через Qwen Chat со встроенным подключением GitHub; наличие `gh` в командной строке необязательно для такого сценария.
- Не объясняй ошибку «проблемами токена» без подтверждения GitHub.
- Если PR не создаётся, назови **конкретную GitHub-ошибку**. Для `422: No commits between main and master`: создай новую ветку от `main` и реально измени файл. Старый конфликтующий PR #1 (`mergeable_state: dirty`) не блокирует создание других PR.
- Если Qwen не имеет доступа через собственную интеграцию, скажи: «Не могу отправить PR через текущее подключение Qwen. Проверь GitHub в настройках Qwen и доступ приложения к репозиторию». **Не проси секреты.**
- Не заявляй об успешном PR без подтверждённой ссылки. Не форсируй `main` и не стирай другие ветки.

Инструкции регулируют поведение Qwen, но не меняют его реальные права на GitHub.
